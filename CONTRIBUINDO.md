# Como contribuir

1. Crie uma branch a partir da `main` (ex.: `docs/minha-mudanca`).
2. Faça commits pequenos, com mensagens claras (ex.: `docs: corrige link`).
3. Envie a branch com `git push` e abra um Pull Request com `gh pr create`.
4. Depois da revisão, o PR é mesclado na `main`. Ninguém faz commit direto na `main`.
